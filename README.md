# Givit: Social Media App (Flutter)

**A social media app with a photo feed, stories, user profiles, followers and posts.**

Built by [Oriental Tech Solutions](https://github.com/OrientalTechSolutions) · Flutter · iOS & Android

---

## What we built

- **Home feed** with photo posts, likes, comments and hashtags
- **Stories** at the top of the feed
- **User profiles** with posts, photos and videos tabs
- **Followers and following**, with follow and unfollow
- **Notifications** for new activity

## Tech stack

`Flutter` `Dart` `Firebase` `Cloud storage` `Push notifications`

## Our role

UI implementation, app development, feed and profile features, testing and release.
